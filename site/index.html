Method

Unified descriptor score

score = 0.70·ALogP − 0.012·PSA − 0.18·HBD − 0.06·HBA − 0.001·MW + 0.035·RTB + 0.10·aromatic rings

The bounded index is sigmoid(−2.1 + score). The interface applies the same coefficients and cutoffs to archived local records and to live ChEMBL records with all seven required descriptors.

Lower

Score below −0.2563230877.

Leaky

Score from −0.2563230877 to below 0.1453605434.

High

Score from 0.1453605434 to below 2.1.

Very high

Score at or above 2.1, corresponding to an index at or above 0.50.

This score is a descriptor-only prioritization proxy. It is not an absolute permeability, leakage constant, or substitute for measurements in the exact oil, surfactant, droplet, temperature, pH, and device-material system.

Architecture

What loads and when

  1. Initial visit: the browser downloads the application and compact 16k atlas.
  2. Local search: names and identifiers are searched entirely in-browser with no external request.
  3. Fallback: if no local record is found, the user can explicitly search ChEMBL.
  4. Live calculation: the browser calculates the proxy when ChEMBL supplies all required descriptors.
  5. Missing properties: the record remains unscored; when a different ChEMBL parent exists, the interface offers a separately labeled parent calculation.
